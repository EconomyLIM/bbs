# bbs

# 프로젝트 개요
[배운것들을 써먹어 보자]

이 프로젝트는 **인증 및 게시판 시스템**을 구현한 애플리케이션입니다.  
프론트엔드와 백엔드 기술 스택을 활용하여 사용자 인증과 게시판 CRUD 기능을 제공합니다.



# 기술 스택

### 프론트엔드
- **TypeScript**
- **Next.js**

### 백엔드
- **Spring Boot 3.4.0**
  - Gradle Build
  - Lombok
  - Spring Security 6
  - Swagger
  - Jasypt
- **데이터베이스**
  - Oracle
  - H2Database
- **캐시**
  - Redis
- **테스트**
  - JUnit 5
- **인증**
  - JWT(Json Web Token)
- **통합 알림**
  - Slack API 연동
